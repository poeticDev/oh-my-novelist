## 시나리오 2: 세계관 설계로 넘어가기

**작가**: "세계관 먼저 만들고 싶어"

**Director** → **World Builder Agent** 호출

### World Builder Agent 대화
```
🌍 World Builder입니다.

[직장인 마법사] 세계관을 설계하겠습니다.

**마법 시스템 제안:**

원리: 마법은 "의도의 구체화"
- 프로그래밍 언어처럼 명확한 문법 존재
- 마력은 정신력에서 유래
- 디버깅이 필요함 (시행착오)

희소성: 
- 마법 각성자는 인구의 0.1%
- 각성은 보통 10대에 일어남
- 주인공은 30대에 늦각성 (이례적)

대가:
- 마법 사용 시 정신적 피로
- 과다 사용 시 기억 상실
- 마력 고갈 시 의식 상실

이런 규칙 어떠세요? 
수정하거나 추가할 부분 있으신가요?
```

**작가**: "마법사들이 IT회사를 왜 선호하는지도 설명해줘"

**World Builder Agent**:
```
좋은 질문이에요! 사회 구조까지 설계하겠습니다.

**마법사가 IT회사를 선호하는 이유:**

1. **논리적 사고의 유사성**
   - 마법 시전 = 코드 작성
   -  다 명확한 문법과 구조 필요
   - 디버깅/디버깅 개념 동일

2. **마스킹 효과**
   - 개발자들의 독특한 행동이 마법 사용으로 오인되지 않음
   - "또 밤새 코딩했네" vs "마법 연구했네"

3. **효율적인 마력 사용**
   - 서버실의 전자기장이 마력 안정화에 도움
   - 24시간 운영이라 야근이 마력 충전 시간으로 위장 가능

4. **커뮤니티 형성**
   - 마법사들끼리 자연스럽게 모임
   - 상호 보호와 정보 공유

**사회적 위치:**
- 법적: 특수 능력자로 등록 의무화
- 경제: 고용 시장에서 프리미엄
- 갈등: 일반인과의 불신 관계

이 정도면 깊이 있나요? 
계속해서 역사나 지리도 설계할까요?
```

## 시나리오 3: 캐릭터 설계

**작가**: "주인공 캐릭터 만들자"

**Director** → **Character Designer Agent** 호출

### Character Designer Agent 대화
```
👤 Character Designer입니다.

김민수(32세) 주인공을 설계하겠습니다.

**기본 정보:**
- 이름: 김민수
- 나이: 32세
- 직업: 중소 IT 회사 개발자 (5년차)
- 외모: 평범함, 안경, 지친 눈빛

**장점 3가지:**
1. 논리적 사고 - 코딩하듯 문제 분석
2. 끈기 - 디버깅하듯 끝까지 파고듦
3. 현실적 - 공상보다 실용적 해결책 선호

**단점 3가지:**
1. 소심함 - 갈등을 피하려 함
2. 자기 비하 - "난 특별하지 않아" 고정관념
3. 외로움 - 깊은 관계 맺기 어려워함

**욕망:**
- 표면적: 회사에서 인정받고 승진
- 진짜: 특별한 존재가 되고 싶음 (어린 시절부터)
- 이유: 평범한 삶에 대한 불만

어떤가요? 이 캐릭터 괜찮으신가요?
수정하고 싶은 부분 있으시면 말씀해주세요.
```

**작가**: "좋아! 멘토 캐릭터도 만들어줘"

**Character Designer Agent**:
```
좋습니다! 멘토 캐릭터를 설계하겠습니다.

**박 senior (45세)**

**역할:** 
회사 선배이자 은둔 마법사

**성격:**
- 냉소적이지만 속은 따뜻함
- 실용주의자
- 주인공의 늦각성을 처음 발견

**배경:**
- 20년 전 각성
- 현재는 마법 사용을 최소화
- 주인공에게 기술과 마법의 연결고리를 가르침

**관계:**
- 주인공에게: 엄격한 스승이자 유일한 아군
- 목표: 후계자 양성

이 멘토 캐릭터 어떠세요?
```
